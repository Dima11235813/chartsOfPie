# E03 — Visualization gallery & playgrounds

## Outcome

Users pick from a gallery of visualizations that all react to the same playback, and can play with
the stream: speed, start position, seek, search for digit strings, colour palettes.

## Features (to be broken into files when phase 2 starts)

- [ ] F03.1 — Visualization framework & selector (shared renderer contract, rAF batching,
      reduced-motion, colour-blind-safe palette option)
- [ ] F03.2 — π spiral (dots coloured by digit along an Archimedean/Fermat spiral)
      — `docs/inspiration/put pie in a spiral.PNG`
- [ ] F03.3 — Digit-transition chord diagram (Cristian Ilies Vasile / Martin Krzywinski style)
      — `docs/inspiration/gradient lines from one pie number color to the next based on order.PNG`
- [ ] F03.4 — Digit-neighbour grid (dots in rows, connect equal neighbours)
      — `docs/inspiration/color for number next number color nested within or connect neighbor colors in rows.PNG`
- [ ] F03.5 — Random walk / turtle (digit = direction), circle of fifths walk
- [ ] F03.6 — Playground controls: speed multiplier, start offset, jump to position, digit-string
      search (e.g. the Feynman point "999999" at decimal 762), loop a range
- [ ] F03.7 — Export image (PNG/SVG) of the current visualization
