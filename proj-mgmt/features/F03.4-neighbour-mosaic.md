# F03.4 — Neighbour mosaic

Our third inspiration image (`docs/inspiration/color for number next number …PNG`).

- [x] Digits as coloured dots in rows; each dot is joined to equal earlier neighbours (left,
      up-left, up, up-right), so runs and repeats appear as chains. The Feynman point "999999" at
      decimal 762 is a bright bar.
- [x] Live: starts with big cells (36 px) and steps down (26 → 18 → 13 px) as the frame fills,
      then scrolls with a few rows of headroom so redraws stay rare
- [x] Posters size the grid to fit exactly N digits
- [x] `earlierNeighbours` unit-tested (no wrapping across rows)
- [x] **Choose the width** (owner request): a Columns control (slider, −/+ buttons, Fit) narrows
      or widens the grid; every digit already played re-flows instantly. Digits `n` columns apart
      stack vertically, so a vertical link means "equal to the digit n places earlier" — sweeping
      the width reveals different repeat distances. Cells shrink in steps (36 → 3.5 px,
      `mosaicColumnsCell`, unit-tested) to keep all digits in view before scrolling.
- [x] The column count is part of `VisualConfig` (`viewOptions.mosaic.columns`, 0 = Fit; additive
      with a default), so it is restored from share links; mosaic posters use it too
      (`…-12col.png`, caption "· 12 columns")
- [x] **Groups only** (owner request): show just the digits in groups of 2+ … 5+ equal
      neighbours (8-connected, the same links the mosaic draws); the rest become faint dots, so the
      shapes stand alone. `mosaicGroupSizes` (union-find over the visible window, rows aligned to
      absolute positions), unit-tested; groups are recomputed as they grow
- [x] **Sweep** (owner request): animates the column count from ½× to 1½× the chosen width and back
      (`sweepColumns`, a triangle wave at 2.5 columns/s; ¼ speed with reduced motion), so groups
      migrate past their neighbours, join and split. The saved width is unchanged; `minGroup` and
      `sweep` are additive view options (links, pieces) and posters honour the groups filter
