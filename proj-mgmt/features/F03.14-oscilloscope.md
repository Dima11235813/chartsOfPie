# F03.14 — Oscilloscope

A literal picture of the sound, from a stereo tap on the final mix (`NotePlayer.getWaveform`:
channel splitter + two time-domain analysers).

- [x] **Vectorscope** (default): left vs right rotated 45°. Mono is a vertical line; stereo width
      (reverb, the piano's two microphones) blooms sideways.
- [x] **Waveform** toggle: both channels against time, triggered on a rising zero crossing so the
      trace stands still
- [x] Phosphor persistence (frames fade to transparent) and a glow in the current digit's colour;
      keeps drawing 3 s after pause
