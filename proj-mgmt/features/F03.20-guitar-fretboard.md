# F03.20 — Guitar fretboard

Owner request; design in [R-008 §3](../research/R-008-instruments-and-hardware.md).

- [x] Six strings, frets 0–15 with real (equal-tempered) fret spacing, nut, inlays, string names;
      high string on top like tablature
- [x] Scale map: every position of the current scale's pitch classes in its digit colour — the
      pentatonic "box" shapes appear by themselves
- [x] Fingering model (`viz/fretboard.ts`, unit-tested): each note lights the position nearest the
      hand, preferring low frets and open strings; fading trail; notes sounding together light
      together and coincidental chords are named
- [x] Out-of-range notes fold by octaves and are drawn hollow
- [x] Tunings: standard, drop D, DADGAD, open G — `viewOptions.fretboard.tuning` (additive), saved
      in links
- [x] e2e: draws on desktop, tablet and mobile
