# F03.15 — Typographic π

The digits themselves as the artwork.

- [x] Monospaced grid starting "3." with each digit in its palette colour. Big type steps down
      (34 → 15 px) as the frame fills, then scrolls.
- [x] Runs of three or more equal digits glow behind the type, retroactively for the whole run.
      The Feynman point "999999" at decimal 762 is the famous one (visible in a 1,000-digit
      poster).
- [x] Posters fit exactly N digits (up to 100,000)
- [x] `runLengthEndingAt` unit-tested
