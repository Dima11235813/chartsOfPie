# F03.1 — Visualization registry & shared palettes

## Why

Every view should follow the same colours and plug into the same playback, so new artistic views
are cheap to add and look like one system.

## Delivered

- `components/views.ts` registry drives the View selector (6 views).
- `viz/palettes.ts` + `components/palette.ts` (React context). The "Colours" selector is remembered
  per browser (localStorage, with a fallback when storage is unavailable). Palettes:
  - **Rainbow (original)** — default, the 2019 colours
  - **Colour-blind friendly** — Paul Tol "light" + white; ten distinct colours, which fixes B-013
  - **Scriabin (by pitch)** — colour follows each digit's note through the current scale
  - **Ink** — sequential blues
- All views follow the palette: chart, staff, digit stream, note legend, ring, walk, sunflower.
- `useDigitFeed` (incremental drawing batched per animation frame; full rebuild on reset, resize or
  palette change) and `useCanvas` (DPR-aware sizing) are shared by the canvas views.
- `PerformanceLog.stepCount`/`lastStep` let views replay history from the digit source when opened
  mid-performance.
