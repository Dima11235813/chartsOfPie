# F03.17 — Cymatics (Chladni plate)

- [x] Square plate, mode (n, m): f = cos(nπx)cos(mπy) − cos(mπx)cos(nπy) (`viz/chladni.ts`);
      modes ordered by n² + m² (≈ frequency), so higher notes draw finer figures
- [x] 9,000 grains slide down the vibration energy f² onto the nodal lines with jitter where the
      plate moves (`settleGrains`); a figure forms in about a second and flows into the next
- [x] Unit tests: mode order, diagonal nodal line (and the anti-diagonal when n + m is even),
      gradient vs finite differences, sand converging on the nodal lines
- [x] Sand in the digit's colour (lightened); caption names the note and mode; reduced motion
      slows it
