# F05.3 — Constants: φ, e, √2

## Why

The golden ratio is the owner's first ask and the cheapest new series: a digit stream with the
same shape as π, so after F05.1 it is a data addition plus a picker.

## Stories

- [x] S05.3.1 — `scripts/generate-constants.ts`: φ (integer √5), √2 (integer √2), e (binary
      splitting) to 1,000,001 digits; written to `public/data/*.txt` only if two methods agree
- [x] S05.3.2 — Verification: each file is computed by two independent methods (φ: √5 and
      Fibonacci ratios; √2: √2 and Pell numbers; e: Σ1/k! and its continued fraction) that agree
      on all 1,000,001 digits; tests pin the sha256, check the first 100 digits by both methods
      and recompute the whole file. A published reference file could not be fetched (the build
      network blocks it), so the second method stands in for it
- [ ] S05.3.3 — Lazy-load per constant (**done**: fetched only when picked); PWA precaches π only
      (**open**, coordinate with F10.5)
- [x] S05.3.4 — Number selector in the header tagline ("… digits of [φ (golden ratio) ▾]"), 44 px
      target, works at 360 px; e2e switches to φ and back while paused with pixels drawn (rule 9).
      **Not yet:** the info popover with the OEIS link (moved to M5 with the lessons)
- [x] S05.3.5 — Poster snapshots for φ (walk and mosaic)

## Notes

Decisions D2 (file, not in-browser) and D3 (include e and √2) in R-011 §10. A Newton iteration
that starts below the root gives plausible-looking wrong digits: the reason for two checks.
