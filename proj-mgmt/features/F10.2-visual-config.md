# F10.2 — VisualConfig: one state for the view

## Why

Today the view, chart style and per-view options (clock order, harmonograph pure ratios, scope
mode) live in scattered component state and are lost on reload. Saving needs them in one
versioned, serialisable object.

## Stories

- [x] S10.2.1 — `VisualConfig` v1 in `core/` (view, palette, chartStyle, viewOptions with
      defaults); lift view-local toggles into it (controlled components)
- [x] S10.2.2 — Share links carry it as `&v=…`; links without `v` behave exactly as today
      (fixtures from F10.1 pin this)
- [x] S10.2.3 — Remember the last view — done as “restore last session” (the whole sound + view, D3)
