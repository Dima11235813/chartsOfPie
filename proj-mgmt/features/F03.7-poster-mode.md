# F03.7 — Poster mode

- [x] "Poster" panel: artwork (digit ring, π walk, sunflower, mosaic, string art), digits of π
      (1,000 … 1,000,000, capped per artwork) and size (2048² or 4096²) → PNG download in the
      current palette with a caption
- [x] The same React-free renderers (`src/viz/render/`) draw live views and posters. Posters render
      in 4,000-digit slices with a progress percentage, so the page stays responsive.
- [x] The π walk poster is coloured by position along the path (a sweep through the palette, after
      Bremer). Per-digit colour would turn a million overlapping segments into one colour.
- [x] Timings in headless (software-rendered) Chromium at 2048²:
  - 1M-step walk ≈ 6 s
  - 1M-seed sunflower < 1 s
  - 100k mosaic < 1 s
  - 10k ring ≈ 2.6 s
  - 100k ring ≈ 20 s; it's rasterisation-bound, with one gradient per link, which keeps the weave's
    depth. Batching was measured and rejected: barely faster, and it changes the look.
- [x] Image regression tests: `e2e/poster-snapshots.spec.ts` renders every artwork (first 2,000
      digits, original palette) and compares it with its baseline. Verified to catch a change to
      the ring's link opacity (5% of pixels) and to pass across fresh runs.

Next: SVG export for vector artworks (ring, mosaic, string art), and an OffscreenCanvas worker
for heavy renders.
