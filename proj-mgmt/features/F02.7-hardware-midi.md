# F02.7 — Play through hardware (Web MIDI)

Research: [R-008 §2](../research/R-008-instruments-and-hardware.md). Nord library files are
proprietary and licensed to Nord hardware, so instead the app sends the notes to the instrument
over USB-MIDI and the Nord plays them with its own sounds.

## Stories

- [x] S02.7.1 — MIDI out: device picker, channel, latency, "instrument only / both"; notes
      scheduled on the audio clock (`getOutputTimestamp`), drone as held notes, all-notes-off on
      pause; hidden where Web MIDI is unsupported (Safari); e2e with a mocked `requestMIDIAccess`
- [ ] S02.7.2 — Owner test with the **Nord Electro 4** (owner's model); default latency; per-model Program Change notes
- [ ] S02.7.3 — MIDI in: play the keyboard, the views (fretboard, clock, staff) follow
- [ ] S02.7.4 — Audio in: hardware sound into spectrogram/oscilloscope/recording

## Delivered (S02.7.1)

- `core/midi/liveMidi.ts` (pure, unit-tested): note on/off, program change, panic (CC 64/123),
  `LiveMidiSender` with timestamps, re-strike handling, held drone notes.
- `midi/midiTap.ts`: wraps the player so every note also goes to MIDI on the player's timing grid
  (+100 ms Tone look-ahead + user latency); "Instrument only" silences the built-in sound.
- `midi/useMidiOutput.ts` + `components/MidiPanel.tsx`: connect (permission), device (a Nord is
  picked automatically), channel, play on (both / instrument only), latency, program change;
  reconnects silently once permission was granted; preferences per device in `localStorage`.
- e2e with a mocked "Nord Electro 4 MIDI" output (channel 2, timestamps, All Notes Off on pause).
