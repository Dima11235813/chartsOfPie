# F03.3 — Digit ring / chord ribbons

After Cristian Ilies Vasile and Martin Krzywinski (see R-006).

- [x] Ten coloured arcs; a gradient ribbon (quadratic curve through the centre region) from each
      digit to the next. The k-th occurrence of a digit sits at frac(k/φ) along its arc, so
      endpoints spread evenly and never move.
- [x] Ribbons fade as the ring fills (alpha ∝ 1/√n) so the weave stays readable; the newest link
      is drawn in white
- [x] Transition bubbles outside each arc (area ∝ count of digit → digit transitions)
- [x] Chords formed by coincidence thicken the arcs of their digits
- [x] Rebuilds replay at most the last 20,000 links, while keeping exact transition counts
- [x] Geometry unit-tested (`viz/art.ts`); e2e checks it draws on 3 viewports
