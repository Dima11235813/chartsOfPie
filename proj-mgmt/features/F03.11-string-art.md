# F03.11 — Times-table string art

Modular multiplication on a circle (popularised by Mathologer): 240 points, a string from n to
k·n mod 240.

- [x] k = 2 + d₁ + d₂/10 from the latest two digits (2.0 … 11.9). The figure eases towards each new
      k, so cardioid (k = 2), nephroid (k = 3) and their relatives morph into one another as π plays.
      With reduced motion it jumps instead.
- [x] Strings coloured by n mod 10 in the current palette; chords that form by coincidence make it
      glow
- [x] Formula label in the corner (`n → 5.10 × n (mod 240)`)
- [x] Pure maths unit-tested
