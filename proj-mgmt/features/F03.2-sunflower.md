# F03.2 — Sunflower (phyllotaxis)

Our "put pi in a spiral" inspiration image, built on Vogel's sunflower model.

- [x] Digit n is a seed at r = c·√n, θ = n × golden angle (≈ 137.508°), coloured by digit
- [x] The disc is laid out for a capacity of 400 × 4ᵏ seeds; a rebuild happens only when the
      capacity grows. Seeds are drawn as dots, or as squares when tiny (fast).
- [x] Newest seed ringed
- [x] Geometry unit-tested; e2e checks it draws and redraws on palette change and Reset

Bridge to E05: the same layout will show Fibonacci and φ, the mathematical reason sunflowers
use this angle.
