# F03.5 — π walk

After Nadieh Bremer, "The Art in Pi" (see R-006).

- [x] Each digit is a unit step in one of ten directions (0 = up, clockwise in 36° turns)
- [x] Segments coloured by digit; start dot and current-position ring
- [x] Auto-zoom: when the walk leaves the frame it refits with a 1.6× margin, so refits are rare
- [x] Fast drawing: one path per digit colour, incremental between refits
- [x] Geometry unit-tested; e2e checks it draws on 3 viewports
