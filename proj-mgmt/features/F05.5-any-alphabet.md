# F05.5 — Any alphabet: residues, bases, binary

## Why

"Ten" is hard-coded in about twenty places (R-011 §2). Readings like Fibonacci mod 12 (one
pitch class per step), the binary prime indicator, or π in base 12 need every layer to take an
alphabet size k.

## Stories

- [x] S05.5.1 — Core: the counter and engine already counted k symbols; mapping strategies take
      k (`centred` centres on ⌊k/2⌋, `semitones` = pitch class s for k = 12), the original note
      lengths and the digit-length rhythm read the symbol scaled onto 0–9 (`toDecimalSymbol`,
      decision D7); `Arranger.setAlphabet` from the loaded source; empty counts sized to k
- [x] S05.5.2 — Palettes give one colour per note-table entry, so k colours: ten stay exactly as
      before; others are interpolated (colour-blind: the first k when k < 10); Scriabin follows
      pitch, so mod 12 on semitones from C is his twelve colours in order. Chart (labels 0–9, A,
      B…), stats table, stream, note legend and "Current symbol" show k symbols (`symbolGlyph`)
- [x] S05.5.3 — Views: ring (k arcs, k × k transitions; its centre now shows the number's symbol,
      B-023), walk (k directions), string art (2 + d₁ + d₂/k, k colour batches), typographic glyphs
      past 9. Mosaic, sunflower, Hilbert, sound shapes and cymatics were already alphabet-free
      (colour or notes only). Music clock: a pitch class never heard is a hollow ring, and its
      summary names what is missing ("never F♯ so far")
- [ ] S05.5.4 — `supports(source)` on views; the selector disables and explains unsupported ones.
      Not needed yet: every view handles any k up to 36 (glyphs 0–Z). Add it with the first view
      that cannot (e.g. an Ulam spiral needs k = 2)
- [ ] S05.5.5 — Readings: **`mod-12` for Fibonacci done** (S05.2.4). **`base-12` for Fibonacci
      done** (R-013 L1): every term written in base 12, one after another
      (`fibonacciConcatenated(length, base)`); the Benford table counts first digits 1–B against
      log₁₂(1 + 1/d). Binary (prime indicator), prime gaps and other bases for constants to come
      (R-013 §2)
- [ ] S05.5.6 — Tests: palettes and geometry with k = 2, 4, 10, 12, 16 (`viz/alphabet.test.ts`),
      core and music facts (`core/series/mod12.test.ts`), e2e on a mod-12 source in every digit
      view and back to π (rule 9), poster baselines `mod12-*` for ring, walk, type and string
      art; π and φ baselines and every audio snapshot unchanged. Left: k = 2 and 16 end to end,
      once a reading produces them

## Notes

Reading parameters (the modulus) were planned as an additive `SourceConfig` field (R-011 §6).
Built instead as **fixed reading ids** (`mod-12`): a modulus only matters musically for a few
values (12 pitch classes, 2 for binary), every id is too-new-safe in old apps, and a link stays
readable (`s=fibonacci.mod-12`). Another modulus is another additive id; no version bump either
way. The API validates pieces with the web schema, so it needs a redeploy to accept the new id.
