# F05.5 — Any alphabet: residues, bases, binary

## Why

"Ten" is hard-coded in about twenty places (R-011 §2). Readings like Fibonacci mod 12 (one
pitch class per step), the binary prime indicator, or π in base 12 need every layer to take an
alphabet size k.

## Stories

- [ ] S05.5.1 — Core: counter, mapping strategies (k symbols; `semitones` = chromatic for 12),
      legacy durations scaled onto the ten lengths (decision D7), digit-length rhythm
- [ ] S05.5.2 — Palettes produce k colours (interpolated; Scriabin for 12); chart and stats show k rows
- [ ] S05.5.3 — Views: ring (k arcs, k × k transitions), walk (k directions), string art, cymatics,
      typographic glyphs past 9
- [ ] S05.5.4 — `supports(source)` on views; the selector disables and explains unsupported ones
- [ ] S05.5.5 — Readings `mod` (modulus param) and other bases for constants
- [ ] S05.5.6 — Tests: every renderer with k = 2, 4, 12, 16; e2e on a mod-12 source; π unchanged

## Notes

`SourceConfig.params.modulus` is already in the M1 schema (default 10), so no version bump.
