# S05.1.3 — Series-aware playback hook and labels

**As a** developer **I want** playback to load whichever source the `SourceConfig` names **so
that** switching numbers later is a state change, not a reload.

## Acceptance criteria

- [ ] Given the π source, when the app loads, then the UI reads exactly as today ("π walk",
      "Typographic π", "of 1,000,001 digits lit")
- [ ] Given a different source config, when it changes while paused, then playback resets and
      loads the new source through the same `LoadState` path

## Tasks

- [ ] T1 — `usePiPlayback` → `useSeriesPlayback(sourceConfig)` (keep the injectable loader for tests)
- [ ] T2 — Labels and accessible descriptions take the series symbol and length (registry,
      `views.ts`, Hilbert summary) — ids unchanged (decision D6)
- [ ] T3 — Lab (`posterLab`, `audioLab`) loads through the registry
