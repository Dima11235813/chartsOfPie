# S05.1.3 — Series-aware playback hook and labels

**As a** developer **I want** playback to load whichever source the `SourceConfig` names **so
that** switching numbers later is a state change, not a reload.

## Acceptance criteria

- [x] Given the π source, when the app loads, then the UI reads exactly as today
- [x] Given a different source config, when it changes, then playback loads the new source
      through the same `LoadState` path (the loader is keyed on the config; same number, same
      object, no reload)

## Tasks

- [x] T1 — `App` loads through `loadSource(source)` (tests still inject a loader); `useLinkedState`
      carries the source; opening a piece restores its number. The hook keeps its name
      `usePiPlayback` (renaming is cosmetic; deferred with the labels)
- [x] T2 — Labels and descriptions that say π follow the series (done in M2, F05.3): view names
      ("φ walk"), the stage caption and description, "Where in φ" with the number's own opening
      (1.61803…), poster names and captions, the saved-piece name. The Hilbert summary counts the
      source's length instead of a fixed 1,000,001
- [x] T3 — `posterLab` loads through the registry (`render(kind, { series })`) for the φ poster
      snapshots. `audioLab` still renders π only: sound presets don't depend on the number
