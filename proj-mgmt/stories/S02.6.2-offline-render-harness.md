# S02.6.2 — Offline render & loudness harness

**As a** developer tuning sounds **I want** deterministic renders with objective measurements
**so that** I can compare changes and catch clipping or level jumps automatically.

## Acceptance criteria

- [x] `npm run audio:render` renders presets with the exact live graph (Tone.Offline in Chromium) to `apps/web/audio-renders/*.wav` and `report.md`
- [x] Report: peak, gated loudness (BS.1770 gating, unweighted), RMS, max momentary, clipped samples, spectral centroid, >4 kHz energy
- [x] Options: `PRESETS`, `SECONDS`, `SEED`, `START`, `CALIBRATE` (instrument trims)
- [x] Fails on clipping or loudness outside -14 ± 1.5 dB
- [x] Analysis and WAV encoding are unit-tested
