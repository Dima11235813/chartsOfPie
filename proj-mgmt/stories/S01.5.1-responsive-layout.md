# S01.5.1 — Responsive layout for phone, tablet and desktop

**As a** phone, tablet or desktop user **I want** a layout that fits my screen **so that** I can use it anywhere.

## Acceptance criteria

- [x] No horizontal scroll at 360, 820 and 1280 px widths (asserted in e2e)
- [x] Chart beside the stats panel ≥ 960 px; stacked below; sticky control bar with safe-area padding
- [x] 44 px touch targets, visible focus rings, dark theme with sufficient contrast for text
