# S02.1.2 — Choose scale, root and octave in the UI

**As a** listener **I want** to choose the scale, root note and starting octave while it plays **so that** I can hear how the same digits change mood.

- [x] Given playback is running, when I change scale/root/octave, then the next digit uses the new mapping without restarting
- [x] Defaults reproduce the legacy sound (C major pentatonic from C4)
- [x] Controls are usable on a 360 px wide screen (collapsible “Sound” panel)
- [x] Current mapping is shown as a digit → note legend (0 → C4 … 9 → A5)
