# S02.6.1 — Out-of-the-box presets

**As a** listener **I want** good-sounding presets **so that** I hear what π can sound like without
tweaking anything.

## Acceptance criteria

- [x] Presets: Original (2019, unchanged), Pentatonic piano, Lydian dream, Dorian marimba, Minor nocturne, Music box, Blues pluck, Whole-tone mist, Raw digits
- [x] Dozenal mallets (R-013 L3): chromatic semitones on a soft marimba, so base-12 and mod-12
      symbols are the twelve notes; -14.2 dB gated, no clipping; spectrogram baseline added
- [x] Choosing a preset applies instantly while playing; changing any setting shows “Custom (from …)”
- [x] Every preset is a valid config (unit test), plays in the browser without errors (e2e on 3 viewports), doesn't clip and is loudness-matched to Original within ±1.5 dB (render harness)
- [x] Original arranges every digit exactly like the legacy app (unit test)
