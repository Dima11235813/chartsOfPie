# S02.4.6 — Classic keyboards, acoustic guitar & analog synth

**As a** listener **I want** the famous keyboard and guitar sounds **so that** π sounds like the
records I know. Recipes and rationale: [R-008](../research/R-008-instruments-and-hardware.md).

## Acceptance criteria

- [x] New instruments (ids persisted forever; additive schema change, snapshot reviewed):
      `acoustic-guitar`, `wurlitzer`, `clavinet`, `organ` (drawbars + Leslie-style chorus),
      `analog-synth` (Minimoog-style lead). The FM electric piano is now labelled
      "Electric piano (Rhodes-style)" (id unchanged).
- [x] Calibrated with `CALIBRATE=1 npm run audio:render` to -20 dB ±1, no clipping (trims:
      acoustic -2.3, Wurlitzer +5.3, Clavinet -10.6 with filter Q lowered to 2.5 to tame
      transients, organ -13.7, analog -11.4)
- [x] Presets "Acoustic folk" (G major pentatonic, -14.6 dB) and "Clavinet funk" (E Dorian
      sixteenths, -15.3 dB) with audio snapshot baselines; all other baselines unchanged
- [x] General MIDI programs for MIDI export
