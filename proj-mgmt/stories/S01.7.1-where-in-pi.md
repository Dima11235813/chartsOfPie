# S01.7.1 — "Where in π": jump, search, share

**As a** listener **I want** to start anywhere in π — a decimal place, a famous spot, my birthday —
**so that** I can explore the whole million digits, not just the first few thousand.

## Acceptance criteria

- [x] A "Where in π" card: type a decimal place and Go; Beginning, Feynman point, Random
- [x] Find digits (1–20; "14/03" → 1403) jumps to the first occurrence; "Find next" continues
- [x] Every limit comes from the data loaded (`full.length`), nothing assumes a million: the card,
      the tagline and validation all read it
- [x] Playback starts there instantly (no replay of the digits before it); every view sees a
      performance that starts at that digit; labels show absolute decimal places (digit stream,
      "Decimal place" readout, chord, captions, saved pieces)
- [x] Positions: decimal place n is `digitAt(n)` (0 = the leading 3), unit-tested on the Feynman
      point (762) and the first 0 (32)
- [x] The starting point travels in share links (`&at=762`, left out at 0; old links start at the
      beginning; a bad value is reported) and the last session; saved pieces store
      `position.start` (additive, default 0 — schema snapshot updated with it, fixtures untouched)
- [x] Posters keep using the first N digits
- [x] Works at 360 px; quick picks wrap
