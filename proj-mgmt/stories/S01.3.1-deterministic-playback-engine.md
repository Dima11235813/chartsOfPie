# S01.3.1 — Deterministic playback engine

**As a** developer **I want** a playback engine independent of UI, audio and timers **so that** it is testable and reusable for other sequences.

## Acceptance criteria

- [x] `PlaybackEngine` supports play, pause, toggle, step, reset and stops at the end of the source
- [x] Scheduler and randomness are injectable; tests run deterministically
- [x] Pausing cancels the pending tick so resume never doubles speed (B-012)
