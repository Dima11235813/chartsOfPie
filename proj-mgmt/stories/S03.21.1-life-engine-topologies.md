# S03.21.1 — Life engine: square, graph and line topologies

**As a** builder of views **I want** one Life engine that runs on any lattice **so that** every
view can feed Life without its own simulation code.

## Acceptance criteria

- [ ] Given a square board (wrap or not), when it steps under B3/S23, then a block stays, a
      blinker has period 2, and a glider crosses an 8 × 8 torus in 32 generations (as today).
- [ ] Given dead edges, when a glider reaches a wall, then it breaks up (no wrap).
- [ ] Given a graph topology (compressed neighbour lists), when it steps, then results equal the
      square engine on a graph built from the same grid (property test on random seeds).
- [ ] Given a line and elementary rule 30, 90 or 110, when it steps from a single live cell, then
      the first 8 rows match Wolfram's published patterns (rule 90 = Sierpiński).
- [ ] Given any Life-like rule string (`B36/S23`), when parsed, then birth/survive sets are right
      and bad strings are rejected.
- [ ] The mosaic's Life gives identical generations before and after the move (golden test on a
      fixed seed).
- [ ] A 1024 × 1024 square step is measured and recorded in R-010 (target < 16 ms in a worker).
