# S02.3.1 — Tempo-locked playback with BPM control

**As a** listener **I want** an optional steady tempo **so that** the output sounds like music rather than random beeps.

## Acceptance criteria

- [ ] Timing modes: **legacy random** (default, unchanged) and **tempo** (Tone.Transport at 40–240 BPM, one digit per subdivision)
- [ ] Tempo mode stays in sync with the chart (visual updates driven from the transport callback via `Tone.Draw`)
- [ ] Changing BPM while playing is glitch-free

- [ ] T2 — BPM slider
