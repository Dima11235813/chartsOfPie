# S02.3.1 — Tempo-locked playback with BPM control

**As a** listener **I want** an optional steady tempo **so that** the output sounds like music rather than random beeps.

## Acceptance criteria

- [x] Timing modes: **legacy random** (default, unchanged) and **tempo** (Tone.Transport at 40–240 BPM, one digit per subdivision)
- [x] Tempo mode stays in sync with the chart (visual updates driven from the transport callback via `Tone.Draw`)
- [x] Changing BPM while playing is glitch-free

## Tasks

- [x] T1 — scheduler adapter over Tone.Transport
- [x] T2 — BPM slider
- [x] T3 — tests with fake transport

## Notes / outcome

Implemented without Tone.Transport: the engine aims each tick at an absolute target (`Scheduler.now`), and the player puts notes on an exact audio-clock grid using the previous step's gap. This avoids a second clock while keeping jitter off the audio. Revisit Transport if swing or bar-level scheduling needs it.
