# S02.4.5 — Electric guitar instrument and “Pentatonic rock” preset

**As a** listener **I want** π played on an electric guitar **so that** I hear the digits in the
instrument most people associate with the pentatonic scale.

## Acceptance criteria

- [x] New instrument id `electric-guitar` (persisted forever; additive to the config schema, so
      no version bump — the schema snapshot was updated and reviewed as additive)
- [x] Synthesised, so no samples or licences: detuned saw “string” with a closing filter
      envelope (pick attack) → pickup resonance (peaking 1.4 kHz) → soft-clipping amp
      (`Distortion` 0.3, 2× oversampling) → cabinet (high-pass 90 Hz, 24 dB low-pass 4.5 kHz)
- [x] Calibrated: trim -8.0 dB from `CALIBRATE=1 npm run audio:render` (bare instrument -12.0 dB
      → -20 dB target)
- [x] New preset “Pentatonic rock”: E minor pentatonic from E3, steady eighths with rests at
      104 BPM, accented, light echo; measured -14.3 dB gated loudness, peak -5.1 dBFS, no clipping
- [x] Audio snapshot baseline added (`pentatonic-rock.png`); all other baselines unchanged
- [x] MIDI export maps it to General MIDI 30 “Overdriven Guitar” (program 29, 0-based)

## Notes

Sampled guitars were considered; freely licensed multisamples of good quality are rare, and the
amp/cabinet chain is what makes it read as “electric”. A clean variant (no drive, chorus) or a
power-chord voicing (root + fifth per note) would be natural follow-ups.
