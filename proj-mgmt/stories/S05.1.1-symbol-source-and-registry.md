# S05.1.1 — SymbolSource and series registry (π only)

**As a** developer **I want** the engine to consume a `SymbolSource` from a series registry **so
that** adding φ, Fibonacci or primes later is a data or generator change, not a pipeline change.

## Acceptance criteria

- [ ] Given the app on π, when anything plays, then sound, counts, views, posters and MIDI are
      byte-identical to before (verify-parity, audio and poster snapshots unchanged)
- [ ] Given `core/series/`, when tests run, then the registry holds exactly `pi` with reading
      `digits`, alphabet 10, and `core/` imports no DOM/React/Tone/Chart code
- [ ] Given a source with `alphabetSize` 10, when the counter records a symbol outside 0..9,
      then it throws as today

## Tasks

- [ ] T1 — `core/series/types.ts`: `SymbolSource`, `NumberSeries`, `ReadingDefinition` (R-011 §4)
- [ ] T2 — `DigitSource` becomes an alias of `SymbolSource`; `createDigitSource` sets alphabet 10;
      `digitAt` kept as an alias of `symbolAt`

- [ ] T4 — Registry with π (`asset` spec reusing `pi.ts` validation); persisted ids added to
      `persistedIds.test.ts`
