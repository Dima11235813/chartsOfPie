# S02.3.2 — Selectable rhythm encodings

**As a** composer **I want** to choose how digits become note lengths **so that** rhythm becomes part of the math.

## Acceptance criteria

- [ ] Rhythm encodings: legacy table, all equal, digit = number of 16ths (0 = rest), Euclidean rhythm E(k, 16) where k is the digit
- [ ] Each encoding is pure, tested and selectable
