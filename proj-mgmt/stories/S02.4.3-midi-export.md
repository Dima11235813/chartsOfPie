# S02.4.3 — Export the performance as MIDI

**As a** musician **I want** to export what I heard as MIDI **so that** I can use it in my DAW.

## Acceptance criteria

- [x] Export everything played since Reset (up to 50,000 notes) as a .mid file reproducing notes, durations, velocities and tempo

## Tasks

- [x] T1 — dependency-free Standard MIDI File writer (`core/midi/midiFile.ts`, round-trip tested)
- [x] T2 — export button

## Notes / outcome

Format-1 file: a conductor track (tempo), a melody track with the instrument's closest General MIDI
program, and a drone track when the drone is on. Tempo presets keep their BPM so notes line up
with a DAW's grid.
