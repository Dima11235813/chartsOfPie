# S02.4.1 — Instrument selection

**As a** listener **I want** to choose the instrument **so that** I can find a sound I like.

## Acceptance criteria

- [x] Synth presets (sine, triangle, FM bell, pluck/Karplus-Strong, AM pad) and a sampled piano (lazy-loaded)
- [x] Volume slider in addition to mute

## Tasks

- [x] T1 — instrument registry in the audio adapter
- [x] T2 — UI

## Notes / outcome

8 instruments (`audio/instruments.ts`), calibrated with `CALIBRATE=1 npm run audio:render`. The sampled piano uses vendored Salamander samples (CC BY 3.0, `public/audio/salamander/README.md`). A volume slider sits next to Mute.
