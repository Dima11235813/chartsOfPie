# S02.5.1 — Versioned CompositionConfig with URL sharing

**As a** user **I want** my choices captured in one shareable link **so that** I can send someone exactly what I'm hearing.

## Acceptance criteria

- [ ] `CompositionConfig` (source, start position, scale, root, octave, mapping, rhythm, timing, tempo, instrument, chart style) defined with a zod schema and `version: 1`
- [ ] Config round-trips through the URL (compressed, base64url) and invalid/unknown versions fall back to defaults with a notice
- [ ] Migration function scaffold `migrate(config)` for future versions, with tests

## Tasks

- [ ] T1 — schema + defaults (= legacy)
- [ ] T2 — URL encode/decode
- [ ] T3 — wire UI state to config
- [ ] T4 — tests incl. malicious/oversized input
