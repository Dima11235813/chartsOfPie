# S02.5.1 — Versioned CompositionConfig with URL sharing

**As a** user **I want** my choices captured in one shareable link **so that** I can send someone exactly what I'm hearing.

## Acceptance criteria

- [x] `CompositionConfig` (source, start position, scale, root, octave, mapping, rhythm, timing, tempo, instrument, chart style) defined with a zod schema and `version: 1`
- [x] Config round-trips through the URL (compressed, base64url) and invalid/unknown versions fall back to defaults with a notice
- [x] Migration function scaffold `migrate(config)` for future versions, with tests

## Tasks

- [x] T1 — schema + defaults (= legacy)
- [x] T2 — URL encode/decode
- [x] T3 — wire UI state to config
- [x] T4 — tests incl. malicious/oversized input

## Notes / outcome

`core/composition/config.ts` (zod/mini, `version: 1`). The URL carries `#p=<preset>` or `#c=<base64url config>`; the default preset gives a clean URL. Bad links fall back to the default with a notice.
