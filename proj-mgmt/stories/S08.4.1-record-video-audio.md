# S08.4.1 — Record video and audio of a session

**As a** creator **I want** to record what I see and hear **so that** I can share a π performance.

## Acceptance criteria

- [x] "● Record video" (enabled once audio has started) records until "■ Stop m:ss"
- [x] Video: a 1280×720 compositor mirrors whichever view is on screen (switching views is captured)
      with a caption (preset · digits · last chord), plus the audio output; WebM (VP9/VP8 + Opus) or MP4
- [x] Separate audio-only download; timestamped file names `charts-of-pie-<preset>-YYYYMMDD-HHMMSS.<ext>`
- [x] e2e downloads both files on 3 viewports (sizes > 5 kB / 1 kB)

## Notes

- Uses MediaRecorder + `canvas.captureStream`; unsupported browsers see a hint.
- Background tabs pause `requestAnimationFrame`, which freezes the video picture; the audio keeps
  recording.
