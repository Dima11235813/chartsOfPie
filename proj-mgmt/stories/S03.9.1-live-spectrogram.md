# S03.9.1 — Live scrolling spectrogram view

**As a** curious listener **I want** to see what I'm hearing **so that** I understand harmonics,
loudness and timbre.

## Acceptance criteria

- [x] "Spectrogram" view taps the final mix (before mute) through a Web Audio AnalyserNode (FFT 4096)
- [x] Scrolls right to left, log frequency axis 40 Hz–10 kHz with labels, magma-like colour map
      (dark = quiet, bright = loud); keeps scrolling 3 s after pause so tails stay visible
- [x] Colour and frequency maths shared with the offline snapshot renderer (`viz/spectrogram.ts`,
      unit-tested: a 440 Hz sine lands on the 440 Hz row)
- [x] e2e verifies the live view shows energy after Play on 3 viewports
