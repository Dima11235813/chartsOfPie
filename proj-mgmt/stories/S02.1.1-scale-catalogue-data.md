# S02.1.1 — Scale & mode catalogue in the core

**As a** musician or learner **I want** a catalogue of scales and modes **so that** π can be heard in many musical colours.

## Acceptance criteria

- [x] Catalogue includes: major (Ionian), natural minor (Aeolian), Dorian, Phrygian, Lydian, Mixolydian, Locrian, major & minor pentatonic, blues, harmonic minor, melodic minor, whole tone, chromatic
- [x] The seven diatonic modes are derived by rotating the major scale, and tests confirm each against its textbook spelling
- [x] Every scale has id, name, intervals, family and a one-line character description (e.g. Lydian: “bright, dreamy — raised 4th”)
- [x] Legacy mapping unchanged and its tests still pass

## Tasks

- [x] T1 — `core/music/scaleCatalogue.ts`
- [x] T2 — `rotateIntervals()` helper for modes
- [x] T3 — tests with expected notes per scale from a fixed root
- [x] T4 — review by `music-theory-expert` agent

14 scales in `core/music/scaleCatalogue.ts`; the seven modes are derived by `rotateIntervals` and each is tested against its white-key spelling.
