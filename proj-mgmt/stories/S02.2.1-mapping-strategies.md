# S02.2.1 — Selectable digit → pitch mapping strategies

**As a** composer **I want** to choose how ten digits map onto a scale **so that** I control range and melody shape.

## Acceptance criteria

- [ ] Strategies: **ascending degrees** (legacy: digit n → nth degree, spilling into higher octaves), **wrap within one octave** (n mod scale size), **centred** (5 = root, lower digits descend), **chromatic 0–9 semitones**
- [ ] Each strategy is a pure function `(digit, scale, root, octave) → note` with tests for digits 0 and 9
- [ ] Strategy selection is part of the config (F02.5)
