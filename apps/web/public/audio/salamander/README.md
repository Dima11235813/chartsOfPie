# Salamander Grand Piano (subset)

Samples A1–C7 (every minor third) used by the "Grand piano" instrument.

- **Source:** Salamander Grand Piano V3 by Alexander Holm (Yamaha C5), as redistributed in
  https://github.com/Tonejs/audio/tree/master/salamander
- **Licence:** [Creative Commons Attribution 3.0 (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/)
- **Changes:** none (files copied as published, MP3).

Loaded lazily, only when the piano instrument is selected.
